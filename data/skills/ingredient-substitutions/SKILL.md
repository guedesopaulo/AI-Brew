# Ingredient Substitution Reference

Use when a specified ingredient is unavailable or when adapting a recipe.
Substitutions are ordered by similarity (best match first).

---

## Malt Substitutions

### Base Malts
| Original | Substitutes | Notes |
|----------|-------------|-------|
| 2-Row Pale (US) | Pilsner malt (reduce by 5%), Maris Otter | Pilsner gives slightly lighter, crisper result. Maris Otter adds biscuity character. |
| Pilsner malt | 2-Row Pale (add 5% more), Pale Ale malt | 2-Row slightly less fermentable. Pale Ale adds more body. |
| Maris Otter | 2-Row + 5% Biscuit malt, Golden Promise | Golden Promise is Scottish equivalent — similar character. |
| Vienna malt | Munich malt (use 80% of amount), 2-Row + 5% Crystal 20L | Munich is more intense; reduce amount. |
| Munich malt (Light) | Vienna malt (increase by 20%), 2-Row + 5% Aromatic malt | Vienna is subtler — increase quantity or add Aromatic. |
| Munich malt (Dark) | Munich Light + 5% Melanoidin, Aromatic malt | Melanoidin mimics deep Munich character. |

### Crystal / Caramel Malts
| Original | Substitutes | Notes |
|----------|-------------|-------|
| Crystal 10L | Crystal 20L (reduce by 15%), Carapils + tiny Crystal 20L | Very similar; slightly more color from 20L. |
| Crystal 20L | Crystal 10L + 20%, Crystal 40L - 20% | Interchangeable at ±1 SRM. |
| Crystal 40L | Crystal 30L + 20%, Crystal 60L - 20% | Crystal 60L adds more caramel depth. |
| Crystal 60L | Crystal 40L + 50%, Special Roast malt | Special Roast (50L) is close match. |
| Crystal 80L | Crystal 60L + Crystal 120L (50/50), Cara-Munich II | Cara-Munich II (60-70°L) very similar. |
| Crystal 120L | Special B (70% amount) + Crystal 60L, Crystal 80L + 20% | Special B darker and more intense — reduce. |
| Carapils / Cara-Foam | Flaked wheat (same %) + Crystal 10L, Flaked barley | Adds body/head retention differently. |
| Special B | Crystal 120L + 20%, Dark Crystal + Chocolate malt (tiny) | Special B unique for raisin/plum. Approximate with very dark crystal. |

### Roasted Malts
| Original | Substitutes | Notes |
|----------|-------------|-------|
| Chocolate malt (350°L) | Carafa II (similar), Dark Chocolate malt (adjust %) | Carafa is dehusked — less harsh/astringent. |
| Roasted Barley | Black malt (reduce by 30%), Carafa III (reduce by 30%) | Roasted Barley uniquely dry/acrid — nothing identical. |
| Black Patent malt | Roasted Barley (increase by 30%), Carafa III | Black Patent harsher than Carafa; adjust carefully. |
| Carafa III (dehusked) | Black malt + reduce by 20%, Chocolate malt (increase by 50%) | Carafa gives smoother roast — preferred for Schwarzbier. |

### Specialty Malts
| Original | Substitutes | Notes |
|----------|-------------|-------|
| Flaked Oats | Flaked Barley (same %), Flaked Wheat | Barley slightly more body; wheat adds protein haze. |
| Flaked Barley | Flaked Oats, Flaked Wheat | All three contribute body and protein. |
| Flaked Wheat | Unmalted wheat, Wheat malt (60% of amount) | Wheat malt is malted so more fermentable. |
| Wheat Malt | Flaked Wheat + 20%, 2-Row + 10% | Flaked wheat less fermentable — increase amount. |
| Rye Malt | Flaked Rye (same %), Spelt malt | Rye malt more fermentable but similar spicy character. |
| Melanoidin malt | Aromatic malt (same %), Munich Dark + extra Crystal | Melanoidin adds unique depth — Aromatic is closest. |
| Biscuit malt | Victory malt (same %), Amber malt + 10% | Victory and Biscuit nearly identical. |
| Brown malt | Victory malt + Biscuit malt (50/50 blend), Amber malt | Brown malt unique — approximate with mix. |

### Sugar Adjuncts
| Original | Substitutes | Notes |
|----------|-------------|-------|
| Clear Belgian Candi Sugar | Table sugar (sucrose) — 100% equivalent | Sucrose inverts during boil; identical fermentability. |
| Dark Belgian Candi Sugar D90 | Table sugar + Melanoidin malt (0.5% grist) | Add melanoidin for color; flavor will differ. |
| Dark Belgian Candi Sugar D180 | Table sugar + Special B (1% grist) | For Dubbel/Quad dark fruit notes. |
| Corn sugar (dextrose) | Table sugar — 95% equivalent by weight | Very close; sucrose slightly more fermentable. |
| Honey | Table sugar (use 75% of honey weight) | Honey adds floral aroma — no direct substitute. |
| Lactose | No fermentable substitute. For body: add Carapils or Oats. | Lactose is unfermentable — creates sweetness/body. |

## Hop Substitutions

### By Flavor Profile
| Original | Best Substitute | Notes |
|----------|----------------|-------|
| Cascade | Centennial (use 60%), Amarillo | Centennial more intense — reduce rate. |
| Centennial | Cascade (use 130%), Columbus (bittering only) | Cascade lower AA — increase significantly. |
| Chinook | Columbus + Simcoe blend, Nugget (bittering) | For bittering: Columbus; for flavor: Simcoe. |
| Citra | Amarillo + Mosaic blend (50/50), Galaxy | Blend to approximate Citra's complexity. |

| Simcoe | Chinook + Mosaic (50/50), Columbus | Pine/earthy from Chinook; tropical from Mosaic. |
| Saaz | Tettnang (same rate), Hallertau Mittelfrueh | All noble hops interchangeable at similar rates. |
| Hallertau Mittelfrueh | Tettnang, Saaz | Same noble character. |
| Tettnang | Saaz (same rate), Hallertau | Most interchangeable of noble hops. |
| Fuggle | East Kent Goldings (same rate), Willamette | EKG slightly more floral. Willamette = US Fuggle. |

## Water Profile Substitutions

When specific water profile ingredients are unavailable:
| Target Profile | Key Minerals | Style Application |
|---------------|-------------|-------------------|
| Burton (UK IPA) | High sulfate (500+ ppm) | Enhances hop bitterness perception |
| Dublin (Stout) | High bicarbonate, low calcium | Enhances roast character |
| Pilsen (Czech Pils) | Very soft water, near zero minerals | Clean malt + delicate hop |
| London (ESB) | Moderate bicarbonate + chloride | Rounds malt, softens bitterness |
| Generic Neutral | 50–100 ppm Ca, 50 ppm Cl, 100 ppm SO4 | Works for most styles |

**Quick mineral guide:**
- More sulfate → drier, more bitter perception
- More chloride → rounder, fuller, sweeter perception
- Bicarbonate → raises mash/wort pH (counteract with acid malt or lactic acid)
